# Finora — Next.js Finance & FinTech Landing Page Application

A premium fintech landing application for corporate cards, expense management, real-time cash flow forecasting, and automated accounting.

## 🚀 Port & Development

This application runs on port **9002**:

```bash
npm install
npm run dev
```

Visit: `http://localhost:9002`

## 📄 Pages Included (4 Fully Designed Pages)

1. **Home / Landing Page (`/`)**:
   - Hero section: "Make Every Financial Decision Count"
   - Interactive Financial Pulse Dashboard mockup (Cash runway, ARR, net burn, cash flow bar chart)
   - Real-time expense transaction ledger with OCR auto-reconciliation
   - Native accounting integrations showcase (QuickBooks, Xero, NetSuite, Stripe, Gusto)
2. **Features (`/features`)**:
   - OCR receipt scanning and automated expense matching
   - Real-time runway scenario simulator
   - Interactive Department Budget Controls with live percentage spend progress bars
   - One-click financial reporting and audit trail logging
3. **Pricing (`/pricing`)**:
   - Free Starter ($0), Professional ($47/mo), and Business Scale ($143/mo) plans
   - Interactive Monthly/Yearly toggle with 20% annual savings calculation
   - Comprehensive feature comparison matrix
4. **About & Security (`/about`)**:
   - Financial transparency principles (No hidden FX fees, zero data monetization)
   - SOC 1, SOC 2 Type II, and PCI-DSS Level 1 compliance architecture
   - CFO Consultation & Sales Form with React Hook Form + Zod validation

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (Custom Emerald Green & Charcoal theme)
- **Icons:** Lucide React
- **Forms:** React Hook Form + Zod validation
